# BlinkMyAd Coming Soon

A responsive one-page launch website for **BlinkMyAd**.

## Included

- Official BlinkMyAd brand logo from the primary `advibe` repository
- Premium dark-blue, purple, and cyan design with animated digital billboard
- Responsive desktop, tablet and mobile layouts
- Accessible semantic HTML and reduced-motion support
- SEO and social-sharing metadata
- No backend, framework, external dependency, or build step

## Local preview

Open `index.html` or run:

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Deployment

Deploy as a static site from repository root. No build command is required. The output directory is `.`. Compatible with Vercel, Netlify, Cloudflare Pages and GitHub Pages.
